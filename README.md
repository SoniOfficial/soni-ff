# SONI FF — V1.0

Вебсайти намоишии мобилӣ барои интихоби бастаҳои Free Fire diamonds.

## Оғози маҳаллӣ
Файли `index.html`-ро дар браузер кушоед. Барои GitHub Pages ба танзимоти репозиторий гузаред:
1. Settings → Pages
2. Build and deployment → Deploy from a branch
3. Branch: `main`, Folder: `/ (root)`
4. Save

## Муҳим
- Ин версия demo аст.
- Фармоишҳо танҳо дар `localStorage`-и браузери истифодабаранда нигоҳ дошта мешаванд.
- Пардохти воқеии DC City фаъол нест.
- Барои қабули пардохт backend-и амн, шартномаи merchant/acquiring ва callback-и серверӣ лозим аст. Калидҳои махфӣ ҳеҷ гоҳ дар JavaScript-и браузер ҷойгир карда нашаванд.
- Барои интиқоли воқеии алмос таъминкунандаи ваколатдор/API-и мувофиқ зарур аст.
- SONI FF лоиҳаи мустақил буда, бо Garena ё Free Fire расман вобаста нест.
